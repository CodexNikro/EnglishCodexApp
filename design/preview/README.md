# Recall — интерактивный дизайн-прототип

Один автономный `index.html`, три направления (Paper, Signal, Fieldnotes) и пять экранов. Интерфейс и примерные данные предназначены для выбора дизайна: ИИ, микрофон, хранение прогресса и планировщик повторений не подключены.

Для просмотра можно открыть HTML в браузере. Если среда запрещает `file://`, запустите локальный сервер из этой папки:

```bash
python -m http.server 4173
```

Затем откройте `http://localhost:4173`. Зависимости и сборка не нужны. Внешние скрипты, шрифты и API не используются.

## Пять основных референсов

1. `?theme=paper&screen=today` — спокойная главная с дневным планом.
2. `?theme=paper&screen=recall` — самостоятельное воспроизведение со скрытым английским ответом.
3. `?theme=signal&screen=voice` — тёмная студия разговора.
4. `?theme=signal&screen=progress` — раздельные показатели узнавания, воспроизведения и применения.
5. `?theme=fieldnotes&screen=dictionary` — тёплая тематическая библиотека.

Переключатели сверху меняют тему на любом экране. Навигация слева, а на телефоне снизу, переключает экраны.

## Что можно попробовать

- Раскрыть ответ карточки, запросить подсказку, перейти к следующей карточке через оценку ответа.
- Нажать Space для раскрытия, если фокус не находится на кнопке или в поле ввода.
- Найти слово или перевод, отфильтровать тему, открыть карточку значения. Два значения `book` разделены.
- Перейти из словаря в практику: просмотренное слово отмечается как практика после предъявления, отдельно от независимой проверки.
- Переключить демонстрационное состояние микрофона и показать пример разбора разговора. Записи и отправки звука нет.
- Сравнить все пять экранов в каждой из трёх тем.

Показатели и учебные примеры демонстрационные. Количество записей и тем относится к ранее подготовленной словарной базе; в этом макете загружены только четыре записи. IPA в макете — иллюстрация произношения, не изменение исходной базы.

Скриншоты сняты Chromium: пять desktop при ширине 1440 px и три mobile при ширине 390 px. Проверки зафиксированы в `validation.txt`. После интеграции дополнительно проверены все 15 комбинаций при 360 px, Space и переход из словаря: `integration-validation.txt`. График прогресса согласован с линейной шкалой и подписанными значениями.
